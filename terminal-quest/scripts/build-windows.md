# Building the Windows installer

Two supported routes. Both start from a clone of this folder with Node.js 18+ installed.

## Route A — electron-builder NSIS (one command, recommended)

```bat
npm install
npm run dist
```

Output: `release\TerminalQuest-Setup-1.0.0.exe` — a self-contained NSIS
installer. This is the simplest path and needs no extra tools. `electron-builder`
bundles the Electron runtime, so the target machine needs nothing pre-installed.

## Route B — Inno Setup (if you prefer .iss installers)

```bat
npm install
npm run dist:unpacked        :: produces release\win-unpacked\
node scripts\make-icon.js    :: (re)generate assets\icon.ico if needed
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\terminal-quest.iss
```

Output: `installer\Output\TerminalQuest-Setup-1.0.0.exe`.

## Notes

- Build the Windows installer **on Windows** (or in a Windows CI runner). Cross-
  building from Linux/macOS works for the app bundle but code-signing and the
  NSIS/Inno stages are smoothest on Windows.
- The icon (`assets/icon.ico`, `assets/icon.png`) is generated by
  `node scripts/make-icon.js`; it's committed, so you normally don't need to
  regenerate it.
- To smoke-test before packaging: `npm start` (launches the app), then
  `npm test` (runs the headless engine test suite).
- Player progress is stored in `%APPDATA%\Terminal Quest\saves\` and is **not**
  removed on uninstall, so reinstalling resumes where the player left off.
